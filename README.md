# КОСМОГОЛЬФ — мини-гольф на краю Вселенной

Браузерный мини-гольф на чистом JavaScript + Canvas. Без сборки и зависимостей:
открой `index.html` в браузере — и играй.

## Управление

- **Мышь / палец:** зажми в любом месте поля, потяни назад (как рогатку) и отпусти.
- **R** — начать лунку заново, **M** — звук, **Esc** / правая кнопка — отменить прицел.
- **Enter / Пробел** — дальше на экране счёта.

## 9 лунок, у каждой своя фишка

| # | Лунка | Механика |
|---|-------|----------|
| 1 | Первый удар | Обучение, песок, скошенный борт для рикошета |
| 2 | Мельница | Вращающиеся лопасти, которые толкают мяч |
| 3 | Кротовая нора | Две комнаты без проходов — только порталы |
| 4 | Горизонт событий | Чёрная дыра искривляет траекторию и может съесть мяч |
| 5 | Каток | Лёд, вода и ускоритель |
| 6 | Пинбол | Отбойники и силовое поле, которое снимается кнопкой |
| 7 | Ветродуй | Ветер сносит мяч, камень ездит у прохода |
| 8 | Беглянка | Лунка убегает от мяча |
| 9 | Большой взрыв | Всё сразу: дыра, портал, мельница, лёд и замок |

Ещё: пунктир «призрака» показывает траекторию прошлого удара, комментатор
реагирует на происходящее, звуки синтезируются WebAudio на лету, рекорд
сохраняется в `localStorage`.

## Устройство

- `js/physics.js` — физика (без DOM, работает и в node).
- `js/levels.js` — описание лунок.
- `js/game.js` — рендер, ввод, эффекты, экраны.
- `js/audio.js` — синтезированные звуки.
- `tools/solve.js` — перебором ударов проверяет, что каждая лунка проходима:
  `node tools/solve.js` (или `node tools/solve.js 4` для одной лунки).

Для отладки можно сразу открыть нужную лунку: `index.html#hole=5`.

# КОСМОГОЛЬФ 3D

Трёхмерная версия лежит в папке `3d/`: открой `3d/index.html` (или перейди по ссылке
с титульного экрана 2D). Three.js лежит в `3d/vendor`, так что всё работает без
интернета и без сборки.

## Управление

- **Мышь / палец:** зажми и тяни вниз — клюшка отходит назад (сила удара),
  влево-вправо — прицел (с отведённой клюшкой прицел точнее). Отпусти — замах и удар.
- **Клавиатура:** ←/→ или A/D — прицел (Shift — точнее), держи **Пробел** — шкала силы
  качается, отпусти — удар.
- **Q** — сменить клюшку: **паттер** катит мяч по земле, **вэдж** подкидывает его в воздух.
- **V** — обзор всей лунки, колесо — зум, **R** — заново, **M** — звук.

## 6 лунок на летающих островах

| # | Лунка | Фишка |
|---|-------|-------|
| 1 | Разгон | Горки на дорожке |
| 2 | Холмы | Рельеф катит мяч, бункеры с песком |
| 3 | Мельница | Классическая мельница с лопастями над тоннелем |
| 4 | Трамплин | Ускоритель, трамплин и прыжок через пропасть |
| 5 | Лунная база | Низкая гравитация, узкий мостик, лунка на острове |
| 6 | Бездна | Узкая тропа без бортиков и вращающаяся балка |

Физика — `3d/js/physics3d.js` (рельеф-функция, капсульные столкновения, без
зависимостей). Проходимость лунок проверяет `node tools/solve3d.js`.
